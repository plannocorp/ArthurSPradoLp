# Arthur S. Prado Advocacia — landing page conceito

Landing page estática com layout para computador e celular, menu acessível e CTAs para o WhatsApp público do escritório. Conteúdo baseado nas páginas públicas de www.spradoadvocacia.com. O conceito está identificado como proposta para avaliação.

## Prévia

Abra `index.html` em um navegador ou execute `python3 -m http.server 4173` nesta pasta. Não há instalação de dependências nem etapa de build.

## Entrega

Alterações na branch `homolog`, com Pull Request para `deploy`. O usuário faz o merge. GitHub Pages deve publicar a raiz de `deploy` após o merge.
